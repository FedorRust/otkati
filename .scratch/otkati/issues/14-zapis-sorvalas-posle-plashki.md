# Запись сорвалась после плашки

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 04

## Question

Плашка уже сказала, что откат сохранён, а файл так и не дописался. Что видит Алексей?

Уже решено: плашка выезжает в момент бинда, потому что откат из кольца уже взят, а в папке файл может появиться позже. Этот вопрос про срыв уже после этого: место кончилось на середине очереди, путь стал недоступен, запись оборвалась.

## Answer

Когда запись обрывается уже после плашки «откат сохранён», выезжает вторая плашка тем же движением. По-английски `Couldn't save the clip`, по-русски `Откат не сохранился`. Цвет красный в любой теме. Фокус остаётся в игре, плашка сама уезжает. Недописанный файл в папке не остаётся.
