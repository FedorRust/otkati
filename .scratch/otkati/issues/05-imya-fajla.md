# Имя файла в папке откатов

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by:

## Question

Как называется файл, который бинд кладёт в папку откатов?

Два бинда подряд не должны спорить за одно имя. Папка по умолчанию — `~/Videos/Откаты`.

## Answer

Имя — `otkat` и номер, затем день бинда: `otkat1-2026-10-25`. Номер на один больше самого большого, который ещё лежит в папке. Дырки не заполняются. Пустая папка начинает с `otkat1`. Счётчик общий на всю папку и каждый день не обнуляется. Время в имя не входит. Два отката в очереди получают два соседних номера. День в имени — день бинда, даже если файл допишется после полуночи.
