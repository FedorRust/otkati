# Второй бинд, пока файл ещё пишется

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by:

## Question

Бинд нажат повторно, пока предыдущий откат ещё пишется на диск. Что происходит?

Уже решено, что минутой позже, когда первый файл уже лежит в папке, второй бинд создаёт второй файл. Этот вопрос про окно, в котором первый файл ещё не дописан. Длина по умолчанию — 10 минут.

## Answer

Повторный бинд, пока файл ещё пишется, забирает кольцо как оно есть в эту секунду и становится своим откатом. Первый файл дописывается до конца и не затирается. Следующий ждёт в очереди: одновременно пишется один файл. Плашка «откат сохранён» выезжает сразу на бинде, потому что откат из кольца уже взят, даже если файл появится в папке позже.
