# Какой жест первого запуска копировать

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 02

## Question

В Serpantinum первый запуск и вход настроек — разные жесты. Какой из них программа играет один раз, когда Алексей впервые открывает настройки?

Уже решено: жест один раз, окно после него остаётся на ручках длины и качества, кольцо к этому моменту уже пишет. Этот вопрос только про то, какой жест оболочки копировать.

Три кандидата, по исходникам оболочки на `92e4325`:

- Полноэкранный оверлей `Start.qml`: смывание экрана, набор текста, заливка логотипа. В оболочке это и есть первый запуск, и он один раз.
- Каскад встроенной панели настроек: панель проявляется и чуть увеличивается за 380 мс, сайдбар выезжает, вкладки идут каскадом, контент поднимается. В оболочке это повторяется при каждом открытии панели.
- Короткое проявление отдельного окна настроек, 160 мс. В оболочке у отдельного окна нет каскада.

## Answer

Первый запуск копирует полноэкранный оверлей `Start.qml`: смывание экрана, набор текста, заливка логотипа. Он играется один раз, когда Алексей впервые открывает настройки. После оверлея окно остаётся на ручках длины и качества. Следующие открытия настроек этот оверлей не играют. Кольцо к этому моменту уже пишет.
