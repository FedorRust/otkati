# Файл кольца на диске

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 09

## Question

Когда в настройках выбрано «диск», куда пишется само кольцо?

Это не файл отката в папке откатов. Кольцо — крутящиеся последние минуты, старые секунды затираются новыми. Нужно место этого кольцевого файла.

## Answer

Когда выбрано место «диск», кольцо лежит в `~/.local/state/otkati/ring`. Программа создаёт эту папку сама. Это не папка откатов: черновик не лежит рядом с `otkat1-2026-10-25.mp4`.
