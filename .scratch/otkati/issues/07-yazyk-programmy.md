# Язык программы

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by:

## Question

На каком языке программа говорит с Алексеем: плашка, настройки, первый запуск?

Темы берутся из Serpantinum, у оболочки есть свой язык интерфейса. Совпадает ли язык программы с языком оболочки или он фиксирован.

## Answer

Программа говорит по-английски. В настройках можно перейти на русский. Своей привязки к языку оболочки нет. Плашка, настройки и первый запуск используют выбранный язык. Пока Алексей не переключил, первый запуск тоже английский.
