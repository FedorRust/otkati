# 07 — Нет места

**What to build:** Когда на диске нет места, бинд не оставляет готовый откат. Человек видит плашку «нет места», красную в любой теме.

**Blocked by:** 03 — Первый откат

**Status:** ready-for-agent

- [ ] При нехватке места готового отката в папке нет
- [ ] Недописанный файл не остаётся как готовый откат
- [ ] Плашка красная в любой теме
- [ ] Это отдельный вид плашки: не «сохранять нечего» и не «откат не сохранился»
- [ ] Фраза этой плашки в спеке не задана; тикет её не вводит
