# 01 — Пустое кольцо

**What to build:** Человек нажимает бинд `Alt+Z`, когда кольцо ещё не держит ни одного кадра. На мониторе кольца около двух секунд видна красная в любой теме плашка. По-английски текст `Nothing to save`, по-русски `Сохранять нечего`. Фокус остаётся в игре. Файла в папке откатов нет. Кольцо — процесс на Rust, лицо — процесс на QML.

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] Кольцо и лицо работают двумя процессами: кольцо на Rust, лицо на QML
- [x] Бинд по умолчанию `Alt+Z`
- [x] Пока в кольце нет кадра, бинд не создаёт файл
- [x] Плашка красная в любой теме, с текстом `Nothing to save` или `Сохранять нечего`
- [x] До смены языка виден английский текст
- [x] Плашка держится около двух секунд и уходит сама
- [x] Фокус остаётся в игре
- [x] Проверка смотрит на событие плашки и на отсутствие файла. Протокол между процессами и протокол захвата предметом теста не являются
