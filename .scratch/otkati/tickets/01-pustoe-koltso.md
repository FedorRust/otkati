# 01 — Пустое кольцо

**What to build:** Человек нажимает бинд `Alt+Z`, когда кольцо ещё не держит ни одного кадра. На мониторе кольца около двух секунд видна красная в любой теме плашка. По-английски текст `Nothing to save`, по-русски `Сохранять нечего`. Фокус остаётся в игре. Файла в папке откатов нет. Кольцо — процесс на Rust, лицо — процесс на QML.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Кольцо и лицо работают двумя процессами: кольцо на Rust, лицо на QML
- [ ] Бинд по умолчанию `Alt+Z`
- [ ] Пока в кольце нет кадра, бинд не создаёт файл
- [ ] Плашка красная в любой теме, с текстом `Nothing to save` или `Сохранять нечего`
- [ ] До смены языка виден английский текст
- [ ] Плашка держится около двух секунд и уходит сама
- [ ] Фокус остаётся в игре
- [ ] Проверка смотрит на событие плашки и на отсутствие файла. Протокол между процессами и протокол захвата предметом теста не являются
