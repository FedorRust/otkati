# 05 — Очередь

**What to build:** Пока первый откат ещё пишется, повторный бинд забирает кольцо как оно есть в эту секунду и встаёт в очередь. Очередь пишет по одному файлу, в порядке биндов. Оба момента остаются на диске. Два отката из очереди получают соседние номера. Плашка успеха выезжает на каждый бинд сразу, не дожидаясь конца записи.

**Blocked by:** 03 — Первый откат

**Status:** ready-for-agent

- [ ] Повторный бинд во время записи не ждёт конца первого файла и не затирает его
- [ ] В очередь попадает кольцо на момент этого бинда
- [ ] Файлы пишутся по одному, в порядке биндов
- [ ] Два отката в очереди получают два соседних номера
- [ ] На каждый бинд плашка успеха выезжает в момент нажатия
