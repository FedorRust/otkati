# 13 — Выключатель

**What to build:** Выключатель останавливает набор кольца и программу не закрывает. Пока кольцо выключено, бинд откат не сохраняет и показывает плашку обычного цвета темы. Включение начинает кольцо заново, так что минуты простоя в следующий откат не попадают.

**Blocked by:** 03 — Первый откат

**Status:** resolved

- [x] Выключение останавливает кольцо и оставляет программу запущенной
- [x] Бинд при выключенном кольце файл не создаёт
- [x] Плашка в этом случае цветом темы
- [x] Фраза этой плашки в спеке не задана; тикет её не вводит
- [x] Включение начинает кольцо заново
- [x] Минуты, пока кольцо было выключено, в следующий откат не входят
- [x] Лицо отдаёт выключатель кольцу
