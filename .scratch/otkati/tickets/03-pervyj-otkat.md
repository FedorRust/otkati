# 03 — Первый откат

**What to build:** Когда кольцо уже держит кадры, бинд кладёт новый mp4 в папку откатов и в тот же момент показывает плашку успеха. Длина файла равна тому, сколько кольцо уже набрало, и не больше выбранной длины. Пустые секунды до выбранной длины в файл не дописываются. Кольцо после бинда продолжает крутиться. Имя — `otkat`, номер, день бинда и `.mp4`, например `otkat1-2026-10-25.mp4`. Пустая папка начинает с `otkat1`. Номер на один больше самого большого, который ещё лежит в папке. Дырки не заполняются, и счётчик каждый день не сбрасывается. День в имени — день бинда, в том числе если файл дописан после полуночи.

Кадры на этом тикете уже лежат в кольце. Живой захват монитора Hyprland собирает следующий тикет.

**Blocked by:** 01 — Пустое кольцо

**Status:** ready-for-agent

- [ ] Папка откатов по умолчанию `~/Videos/Откаты`; если её нет, программа создаёт её сама
- [ ] Бинд при непустом кольце пишет новый файл и не затирает уже лежащие
- [ ] Пустая папка даёт имя с номером 1: `otkat1-YYYY-MM-DD.mp4`
- [ ] Номер на один больше максимального, который ещё лежит в папке; удалённый номер снова не выдаётся
- [ ] Общий счётчик на всю папку, без сброса каждый день
- [ ] День в имени — день бинда, в том числе когда запись заканчивается на следующий день
- [ ] Окончание всегда `.mp4`
- [ ] Длина файла равна набранному и не больше выбранной длины; пустых секунд до выбранной длины нет
- [ ] Плашка успеха выезжает в момент бинда, раньше появления файла в папке
- [ ] Плашка успеха — обычная, не одна из трёх красных тревог. Её фраза в спеке не задана, и тикет её не вводит
- [ ] После бинда кольцо продолжает крутиться
- [ ] Проверка идёт по контракту шва и по файлу на диске
