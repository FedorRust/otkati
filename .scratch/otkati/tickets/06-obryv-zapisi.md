# 06 — Обрыв записи

**What to build:** Если запись обрывается уже после плашки успеха, человек видит вторую плашку. Она красная в любой теме. По-английски текст `Couldn't save the clip`, по-русски `Откат не сохранился`. Недописанный файл исчезает из папки откатов. Следующий откат из очереди начинает писаться после этого удаления.

**Blocked by:** 05 — Очередь

**Status:** ready-for-agent

- [ ] Срыв после плашки успеха показывает вторую красную плашку с текстом `Couldn't save the clip` или `Откат не сохранился`
- [ ] Недописанный файл не остаётся в папке откатов
- [ ] Следующий в очереди начинает писаться после удаления оборванного
- [ ] Один срыв не останавливает очередь
